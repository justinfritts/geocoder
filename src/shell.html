3. Geocode

This applies only to places that could not be found. A row that names no city already resolves to its state or country centre regardless of this setting, because there is nothing else it could mean.

Off by default. This is not “pick the biggest”: a candidate qualifies only at 50,000 people and twenty times the next one. That resolves Busan, KOR, which matches a city of 3.3 million and a hamlet in Jangseong-gun, while leaving Springfield, USA ambiguous — Missouri, Massachusetts and Illinois are 167,882, 153,606 and 116,565, and there is no honest way to choose. Rows decided this way say so in the Status column.

On Chrome and Edge you will be asked where to save first, and the result is written to that file as it is produced rather than held in memory. That is what makes a multi-million row file possible — and why re-running one needs the file dropped in again. Other browsers keep the result in memory and offer a download at the end.

Five columns are added to your file: Latitude, Longitude, Matched Place, Match Type and Status. A row that could not be placed comes back with empty coordinates and the reason in Status — never with a guess.
